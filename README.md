# VoxelCraft 3D

Un clone de Minecraft en 3D, hecho desde cero con Three.js y chunks infinitos generados alrededor del jugador.

## Características

- Mundo 3D tipo voxel
- Generación procedural del terreno
- Árboles y estructuras simples
- Entidades sencillas (mobs básicos)
- Movimiento en primera persona
- Salto, cámara, minería y colocación de bloques
- Carga de chunks al moverse para simular un mundo infinito

## Cómo ejecutar

1. Abre una terminal en la carpeta del proyecto.
2. Ejecuta:

```bash
python3 -m http.server 8000
```

3. Abre en el navegador:

```text
http://localhost:8000
```

## Controles

- W A S D: mover
- Espacio: saltar
- Mouse: mirar alrededor
- Click izquierdo: destruir bloque
- Click derecho: colocar bloque

## Notas

Este proyecto está pensado como una base jugable ligera y fácilmente ampliable. Puedes añadir más bloques, biomas, inventario, crafting, enemigos, sonido, y generación más compleja.
